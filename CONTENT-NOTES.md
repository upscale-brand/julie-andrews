# Julie Andrews website content notes

This draft adapts the supplied single-page nutrition website template for Julie Andrews and The Healthy Epicurean. The visible logo is a text wordmark using the client name, “Julie Andrews.” The original page structure, navigation, palette controls and interactions are retained.

## Brand colors

The live website palette was sampled visually from the page and logo treatment; the gold varies with gradient and screen rendering, so these are practical approximations rather than verified source design tokens:

- Warm white: `#FCFBF7`
- Gold: `#D0B34B`
- Charcoal: `#171717`

The site name/logo reference is The Healthy Epicurean. This draft uses the requested client-name wordmark instead of reproducing the current logo image.
